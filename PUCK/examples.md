## 1. Single-qubit X gate

Flip a qubit from |0> to |1> with the Pauli-X (NOT) gate.

Every qubit starts in |0>. The X gate is the quantum NOT: it swaps the amplitudes of |0> and |1>, so the qubit ends in |1> with certainty. Measuring always returns 1.

**Gates**

- `x` — Bit flip |0> -> |1>

## 2. Hadamard superposition

Create an equal superposition and observe 50/50 measurement statistics.

H maps |0> to (|0> + |1>)/sqrt(2). Both outcomes have amplitude 1/sqrt(2), so each has probability 1/2. Individual shots are random; the histogram converges to 50/50 as shots increase (statistical spread about 1/sqrt(shots)).

**Gates**

## 3. Bell state (entanglement)

Entangle two qubits so their measurements are perfectly correlated.

H puts q0 in superposition; CNOT (control q0, target q1) copies the basis value onto q1, producing (|00> + |11>)/sqrt(2). The two qubits always agree: you see 00 or 11, never 01 or 10. Bitstrings are written q1q0 (qubit 0 rightmost), matching Qiskit.

**Gates**

- `h` — Superposition on q0
- `cx` — Entangles q1 with q0

## 4. GHZ state (4 qubits)

Extend entanglement to four qubits: all-zeros or all-ones.

A chain of CNOTs spreads q0's superposition to every qubit, creating (|0000> + |1111>)/sqrt(2). Raise the qubit count (up to 8) and add CNOTs to grow the GHZ state.

**Gates**

- `h` — Superposition on q0

## 5. Quantum teleportation

Move an unknown qubit state from q0 to q2 using entanglement (deferred-measurement form).

RY(1.2) prepares a 'message' state on q0. q1 and q2 share a Bell pair. Alice's CNOT and H entangle the message with her half of the pair. Bob's X and Z corrections are applied as controlled gates (CX from q1, CZ from q0) instead of classical if-statements, which is equivalent by the principle of deferred measurement. To prove the state arrived, the circuit then applies RY(-1.2) to q2: if teleportation worked, q2 is back in |0> on every shot. Alice's two bits (c0, c1) stay uniformly random.

**Gates**

- `ry` — Prepare the message on q0; undo it on q2 to verify
- `h + cx` — Shared Bell pair and Alice's Bell-basis rotation
- `cx, cz` — Bob's X and Z corrections (deferred measurement)
- `measure` — Alice's bits c0, c1 and Bob's verification bit c2

<details><summary>OpenQASM 2.0</summary>

```qasm
OPENQASM 2.0;
include "qelib1.inc";
qreg q[3];
creg c[3];
ry(1.2) q[0];
h q[1];
cx q[1],q[2];
cx q[0],q[1];
h q[0];
cx q[1],q[2];
cz q[0],q[2];
ry(-1.2) q[2];
measure q[0] -> c[0];
measure q[1] -> c[1];
measure q[2] -> c[2];
```

</details>

## 6. Deutsch–Jozsa algorithm

Decide with one oracle query whether a 3-bit function is constant or balanced.

The oracle f(x) = x0 XOR x1 XOR x2 is balanced (half of the inputs give 1). The ancilla q3 is prepared in |-> (X then H) so the oracle's CNOTs kick a phase (-1)^f(x) back onto the inputs. After the final Hadamards a constant function gives 000 with certainty; any balanced function gives a non-zero string. This oracle yields 111. Delete the three CNOTs (constant f = 0) to see 000 instead.

**Gates**

- `x, h on q3` — Ancilla in |-> for phase kickback
- `h on inputs` — Query every input in superposition
- `cx x3` — Balanced oracle f(x) = x0 ^ x1 ^ x2
- `h, measure` — Interfere and read the answer

<details><summary>OpenQASM 2.0</summary>

```qasm
OPENQASM 2.0;
include "qelib1.inc";
qreg q[4];
creg c[3];
x q[3];
h q[0];
h q[1];
h q[2];
h q[3];
cx q[0],q[3];
cx q[1],q[3];
cx q[2],q[3];
h q[0];
h q[1];
h q[2];
measure q[0] -> c[0];
measure q[1] -> c[1];
measure q[2] -> c[2];
```

</details>

## 7. Grover search (3 qubits)

Amplify the marked item |101> out of 8 with two Grover iterations.

Start in a uniform superposition over 8 items. The oracle (X on q1, CCZ, X on q1) flips the phase of |101> only. The diffusion operator (H, X, CCZ, X, H) reflects every amplitude about the mean, amplifying the marked one. After the optimal 2 iterations the marked state has probability sin^2(5 theta) with sin(theta) = 1/sqrt(8), about 94.5%; the other 7 states share the remainder.

**Gates**

- `h` — Uniform superposition / basis change
- `x + ccz + x` — Oracle: -1 phase on |101>
- `h, x, ccz, x, h` — Diffusion (inversion about the mean)

## 8. Quantum Fourier transform (3 qubits)

Apply the QFT to the basis state |5> and inspect the resulting phases.

X on q0 and q2 prepares |101> = |5> (q0 is the least-significant bit). The QFT is built from Hadamards, controlled-phase rotations CP(pi/2) and CP(pi/4), and a final SWAP that reverses qubit order. It maps |x> to (1/sqrt(8)) sum_k exp(2 pi i x k / 8) |k>. All eight outcomes are equally likely (1/8 each): the information is in the phases, visible in the state-vector view where amplitude k has phase 2 pi * 5k / 8.

**Gates**

- `x` — Prepare the input |5>
- `h` — Fourier basis on each qubit
- `cp` — Controlled phase rotations pi/2 and pi/4
- `swap` — Reverse qubit order

<details><summary>OpenQASM 2.0</summary>

```qasm
OPENQASM 2.0;
include "qelib1.inc";
qreg q[3];
x q[0];
x q[2];
h q[2];
cp(pi/2) q[1],q[2];
cp(pi/4) q[0],q[2];
h q[1];
cp(pi/2) q[0],q[1];
h q[0];
swap q[0],q[2];
```

</details>
